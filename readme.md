# Electronic Calculator

### Project Overview

Electronic Calculator is a Python-based program designed to perform basic electrical calculations.
The project provides a simple menu interface for students and beginners to calculate electrical values.

### Features

- Ohm's Law calculator
- Power calculator
- Series resistance calculator
- Parallel resistance calculator
- Series circuit calculator
- Parallel circuit calculator
- Input validation
- Error handling

### Technologies Used

- Python 3
- VS Code
- GitHub

###  Non-Functional Requirements

### Usability
The application should have a simple menu so that beginners can easily use it.

### Reliability
The application should provide correct results for valid inputs.

### Performance
Calculations should be performed quickly without unnecessary delay.

### Maintainability
The program should be divided into separate Python modules so that individual parts can be modified easily.

### Portability
The application should run on systems that have Python 3 installed.

### Security
The application should not require sensitive personal information from users.
