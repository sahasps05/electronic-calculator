# Electronic Calculator - Project Statement

## 1. Problem Statement

Electrical and electronics students often need to calculate voltage, current, resistance, power, and circuit resistance while studying basic electrical concepts. Doing these calculations manually can take time and may lead to calculation errors.

The Electronic Calculator is a Python-based application that provides simple electrical calculations through a menu-driven interface.

## 2. Project Scope

The project focuses on basic electrical calculations used by  engineering students.

The calculator provides:

- Ohm's Law calculations
- power calculations
- Series resistance calculations
- Parallel resistance calculations
- Series circuit calculations
- Parallel circuit calculations

## 3. Target Users

The target users are:

- Engineering students
- Electronics students
- Electrical students
- Beginners learning basic electrical calculations

## 4. Features

### Ohm's Law
- Find voltage
- Find current
- Find resistance

### Power Calculator
- Calculate power using voltage and current
- Calculate power using current and resistance
- Calculate power using voltage and resistance

### Resistor Calculator
- Calculate series resistance
- Calculate parallel resistance

### Circuit Calculator
- Calculate resistance of a series circuit
- Calculate resistance of a parallel circuit

### Validation
- Checks invalid numerical input
- Prevents division by zero
- Prevents negative values

## 5. Technologies Used

- Python 3
- VS Code
- Python testing
- GitHub

## 6. Project Outcome

The project provides a simple tool for performing electrical calculations while demonstrating modular programming, functions, input validation, testing.
